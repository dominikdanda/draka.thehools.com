# TheHools 2.0 — HTML/CSS/JS template

Statyczny, responsywny szablon dashboardu przygotowany na podstawie dostarczonego zrzutu ekranu.

## Pliki
- `index.html` — struktura widoku
- `style.css` — layout, panele, responsywność i efekty
- `script.js` — aktywne menu, prosty licznik wydarzenia i mikrointerakcje

## Uruchomienie
Otwórz `index.html` w przeglądarce albo wrzuć folder na dowolny serwer statyczny.
